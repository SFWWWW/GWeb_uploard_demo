使用说明

本地演示与跨设备云端部署的配置方式。

1. 快速本地演示

默认使用浏览器本地存储（localStorage），打开页面即可创建研究对象、生成二维码、上传照片。适合在同一台电脑上演示完整界面流程。

注意：本地模式下手机扫码上传的数据只保存在手机浏览器里，不会同步到电脑后台。

2. 开启跨设备同步

  1. 在 Supabase 新建项目，进入 SQL Editor 执行仓库中的 supabase.sql。
  2. 打开 js/config.js，将 mode 改为 'supabase'，填入 supabaseUrl 与 supabaseAnonKey。
  3. 将 siteBaseUrl 填为 GitHub Pages 访问地址（以 / 结尾），例如 https://用户名.github.io/仓库名/demo/。
  4. 提交到 GitHub，在 Settings → Pages 中选择分支根目录（若 demo 在子目录，访问 /demo/）。

anon key 可以公开在前端；service_role key 绝不可写入前端。演示策略允许匿名读写，正式研究请增加登录与行级安全策略。

3. 二维码与参数

每个研究对象自动获得形如 P001 的编号。二维码指向 upload.html?pid=P001，扫码后页面自动锁定研究对象，无需手动输入。

如需按天区分，可在链接后追加 &day=3（当前演示仅记录，不参与归档）。

4. 拍摄时间与位置

上传页在压缩图片之前读取原始照片的 EXIF 信息，提取拍摄时间与 GPS 坐标，并通过公开地理编码服务转换为地名。后台照片卡片显示时间与位置标签，点击可查看详情。

若手机相机未开启定位权限，照片可能不含 GPS 信息，此时仍会显示上传时间。
